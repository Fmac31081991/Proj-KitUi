# `componentes/padroes` — acervo da aba Componentes

## O que fica aqui

Catálogo de 36 elementos reutilizáveis — botões, campos, tabelas, navegação, janelas e feedback — com demonstrações prontas.

| Arquivo | Papel |
| :--- | :--- |
| `components.js` | Lista dos componentes com título, grupo, descrição e a demonstração mostrada no canvas. |
| `kit.css` | CSS base do kit, carregado pela aplicação. |
| `kit-css.js` | O mesmo CSS em JavaScript, usado na geração do arquivo exportado. |

## Como é usado

Este acervo vem com o Kit UI e é **somente leitura**. A aplicação carrega estes arquivos pelo `index.html` e eles alimentam `window.KIT_CORE.C`.

Esta aba é de consulta: seu acervo é somente leitura.

Para acrescentar um item, adicione o arquivo aqui e cadastre-o no catálogo da aba. Para conteúdo trazido pelo usuário, use `../importados/`.
