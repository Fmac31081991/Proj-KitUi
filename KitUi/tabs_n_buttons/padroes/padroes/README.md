# `padroes/padroes` — acervo da aba Padrões

## O que fica aqui

Catálogo de 28 telas completas montadas a partir dos componentes: visão geral, painel, login, player e outras.

| Arquivo | Papel |
| :--- | :--- |
| `patterns.js` | Lista dos padrões com título, grupo, tipo, descrição e a tela de demonstração. |

## Como é usado

Este acervo vem com o Kit UI e é **somente leitura**. A aplicação carrega estes arquivos pelo `index.html` e eles alimentam `window.KIT_CORE.P`.

O caminho `padroes/padroes/` repete o nome porque a aba e o acervo chamam-se “Padrões”.

Para acrescentar um item, adicione o arquivo aqui e cadastre-o no catálogo da aba. Para conteúdo trazido pelo usuário, use `../importados/`.
