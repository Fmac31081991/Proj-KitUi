# `kitui_interface/fontes` — fontes da ferramenta

## O que fica aqui

| Arquivo | Papel |
| :--- | :--- |
| `fonts.css` | Declara as famílias `KitUI Inter` (pesos 400 e 600) e `KitUI Mono` (peso 500). |
| `inter-400-normal-latin.woff2` | Texto normal da interface. |
| `inter-600-normal-latin.woff2` | Texto em negrito da interface. |
| `jetbrains-mono-500-normal-latin.woff2` | Números, códigos e rótulos técnicos da interface. |

## Papel distinto do catálogo

Estas três fontes vestem **a ferramenta** — botões, rótulos e painéis do Kit UI. Elas não aparecem na aba **Fontes**.

O catálogo oferecido ao usuário fica em `tabs_n_buttons/fontes/padroes/` com 55 famílias. Inter e JetBrains Mono existem nos dois lugares de propósito: aqui vestem a ferramenta; ali são ativos que podem ser escolhidos para o conteúdo exportado.
